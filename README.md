# Ad-Astra
Ad Astra — the ultimate space exploration mod for Minecraft. Click the link and the .jar downloads instantly — no pages, no waiting. Build rockets, explore the Moon, Mars, Venus, Mercury, and Glacio. Oxygen systems, fuel refining, space stations, rovers, and 250+ building blocks. Works with Fabric, Forge, and NeoForge on 1.18.2–1.21.1.
